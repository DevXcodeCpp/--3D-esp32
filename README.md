# 🕹️ Псевдо-3D Raycasting движок на ESP32с3

Этот проект представляет собой реализацию графического движка **Raycasting** для монохромных OLED-дисплеев. Он преобразует двухмерную карту в трехмерное пространство в реальном времени, используя тригонометрические расчеты и оптимизацию памяти.

## 🧠 Техническая сложность проекта

### 1. Алгоритм Raycasting (Трассировка лучей)

В отличие от стандартной отрисовки спрайтов, этот движок вычисляет расстояние от игрока до стен, пуская лучи веером в пределах поля зрения (**FOV**). Высота стены на экране вычисляется как обратная величина расстояния до неё.

### 2. Оптимизация производительности: Look-Up Tables (LUT)

Вычисление функций `sin()` и `cos()` — это тяжелая операция для микроконтроллера при рендеринге каждого кадра.

* **Решение:** В проекте реализованы таблицы поиска (**LUT**). Значения синусов и косинусов для всех 360 градусов вычисляются один раз при запуске (`setup`) и хранятся в массивах в оперативной памяти, что на порядок ускоряет отрисовку кадра.

### 3. Битовые маски карт

Для экономии RAM карта уровня (`Map`) хранится не в массиве `int`, а в виде **битовых масок** (`uint8_t`). Каждая ячейка карты занимает всего 1 бит, что позволяет хранить огромные пространства в считанных байтах памяти.

## 🛠 Математический аппарат

* **Проекция:** 
* **Векторная физика:** Движение игрока рассчитывается через сложение векторов направления с использованием тригонометрии.
* **Предотвращение искажений:** Для устранения "эффекта рыбьего глаза" (fish-eye effect) используется коррекция лучей относительно угла взгляда (в коде реализована через дельту `rayAngle`).

## 🔌 Схема подключения

| Компонент | Пин (ESP32/Arduino) | Описание |
| --- | --- | --- |
| **OLED SDA** | GPIO 21 / A4 | Данные I2C |
| **OLED SCL** | GPIO 22 / A5 | Тактирование I2C |
| **Кнопка 1** | GPIO 2 | Поворот влево |
| **Кнопка 2** | GPIO 1 | Поворот вправо |
| **Кнопка 3** | GPIO 0 | Движение вперед |

## 🎮 Возможности

* **FPS Counter:** Вывод реальной частоты кадров в Serial-порт для анализа производительности.
* **Collision Detection:** Система проверки коллизий в функции `canMoveTo` не позволяет игроку проходить сквозь стены.
* **Индивидуальная отрисовка:** Рендеринг столбцами (`fillRect`) для создания ощущения глубины на OLED-панели.
